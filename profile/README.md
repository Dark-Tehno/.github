## О нас

**Dark.Tehno** — команда разработчиков, работающая над собственными программными продуктами, инструментами для разработчиков и веб-сервисами.

Мы создаём проекты, которые объединяют программирование, инфраструктуру, автоматизацию и пользовательские приложения. Наша цель — развивать собственную технологическую экосистему, экспериментировать с идеями и превращать их в работающие продукты.


## Наши проекты

### Языки программирования и инструменты разработки

#### [Dark.Lang](https://github.com/Dark-Tehno/Dark-Lang-Source-Code)

Собственный интерпретируемый язык программирования, созданный с упором на понятный синтаксис и расширяемость.

Основные возможности проекта:

* интерпретатор с лексером и парсером;
* объектно-ориентированное программирование;
* взаимодействие с Python;
* менеджер пакетов `dpm` и окружения `denv`;
* компиляция программ;
* расширение для Visual Studio Code.

Ресурсы: [исходный код](https://github.com/Dark-Tehno/Dark-Lang-Source-Code) · [документация](https://vsp210.ru/dark-lang/) · [расширение для VS Code](https://marketplace.visualstudio.com/items?itemName=vsp210.dark-lang)

#### [Dark.WebView](https://github.com/Dark-Tehno/Dark_webview)

Библиотека для языка Dark, предназначенная для разработки веб-приложений и взаимодействия с веб-интерфейсами.

#### [Dark.Custom](https://github.com/Dark-Tehno/DarkCustom)

Python-библиотека для создания более выразительных консольных интерфейсов: цветного вывода, подтверждений, индикаторов прогресса и других элементов.

### Веб-сервисы и приложения

#### [Dark.Chat](https://chat.vsp210.ru/)

Мессенджер для общения между пользователями. Проект развивается как самостоятельный веб-сервис с серверной логикой и взаимодействием в реальном времени.

#### [Dark.Account](https://vsp210.ru/account/)

Система учётных записей и аутентификации для экосистемы Dark.Tehno. Направление разработки включает управление профилями, устройствами, сессиями и механизмами защиты аккаунтов.

#### [Dark.Mail](https://vsp210.ru/mail/)

Почтовый сервис для получения сообщений на временные адреса электронной почты.

#### [Dark.Talk](https://github.com/Dark-Tehno/Dark.Talk)

Клиентское приложение для экосистемы Dark.Talk. Исходный код доступен в отдельном репозитории.

### Системы и игровые инструменты

#### [DarkOS](https://github.com/Dark-Tehno/DarkOS)

Проект операционной среды для OpenComputers, ориентированный на создание собственного интерфейса и программной среды внутри Minecraft.

#### [Dark.Base.Minecraft.Launcher](https://github.com/Dark-Tehno/Dark.Base.Minecraft.Launcher)

Базовый Minecraft-лаунчер с архитектурой, рассчитанной на расширение функциональности с помощью плагинов.

#### [Dark.Terminal](https://github.com/Dark-Tehno/DarkTerminal)

Проект консольного инструмента, развиваемый в рамках экосистемы Dark.Tehno.

## Технологии

В зависимости от проекта мы используем:

* **Языки:** Python, JavaScript, TypeScript, Kotlin, Lua.
* **Backend:** Django, REST API, WebSocket.
* **Frontend:** HTML, CSS, JavaScript, React.
* **Хранение данных и инфраструктура:** SQL, Redis, Linux.
* **Инструменты разработки:** Git, GitHub, Visual Studio Code.
* **Разработка языков:** интерпретаторы, лексеры, парсеры, компиляция и системы управления пакетами.

Стек каждого проекта определяется его задачами и архитектурой.

## Принципы разработки

* **Самостоятельность.** Создаём собственные инструменты и решения.
* **Практичность.** Стараемся превращать идеи в работающие проекты.
* **Развитие.** Постоянно изучаем новые технологии и совершенствуем существующие продукты.
* **Открытость.** Публикуем исходный код отдельных проектов и предоставляем возможность изучать их устройство.
* **Модульность.** Стремимся создавать расширяемые решения, которые можно развивать независимо.

## Участие в проектах

Если тебя заинтересовал один из наших проектов, ты можешь изучить его репозиторий, ознакомиться с документацией и предложить улучшения через GitHub Issues или Pull Requests, если эти функции доступны в соответствующем репозитории.

Перед использованием кода ознакомься с лицензией конкретного проекта: условия распространения могут различаться.
